# وضعیت پیاده‌سازی

## پیاده‌سازی اولیه در مخزن تازه
- پروژه مستقل Kotlin + Compose و workflow ساخت APK دیباگ
- Entity/DAO/Room database و Repository با Flow
- رمزنگاری Room با SQLCipher؛ کلید تصادفی دیتابیس با AES-GCM و کلید پوشانندهٔ غیرقابل‌استخراج در Android Keystore نگهداری می‌شود؛ در صورت گم‌شدن metadata کلید، برنامه از ساخت کلید جایگزین خودداری می‌کند
- قواعد دفتر مالی با مبلغ صحیح در واحد خرد پول (نه Double)
- دسته‌بندی واژه‌محور و پیش‌بینی میانگین متحرک ساده (صریحاً مدل ML آموزش‌دیده نیست)
- تست‌های واحد اولیه

## شکاف‌های مهم؛ هنوز آماده انتشار نیست
- آزمون عملی SQLCipher و سناریوهای بازیابی/از دست رفتن کلید روی دستگاه
- PIN امن و BiometricPrompt
- مشتریان، کالا/موجودی، فاکتور، پرداخت‌ها و عملیات اتمیک مالی
- migrationهای نسخه‌دار و backup/restore امن
- خروجی PDF/XLSX واقعی، نمودارها و گزارش‌های مالی
- UI tests و تست دستگاه/حالت airplane mode
- تست نصب، بررسی دسترس‌پذیری و ارزیابی امنیت

تا زمانی که همه موارد پذیرش و آزمون‌های لازم با شواهد پاس نشده‌اند، APK دیباگ صرفاً artifact توسعه است و نسخه نهایی نیست.
