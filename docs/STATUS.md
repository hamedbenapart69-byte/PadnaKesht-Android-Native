# وضعیت واقعی پروژهٔ پادناکِشت

## قابلیت‌های پیاده‌سازی‌شده در شاخهٔ فعلی

- اپلیکیشن بومی Kotlin + Jetpack Compose + Material 3 با رابط فارسی RTL، تاریخ شمسی، تومان و تم روشن/تیره
- مشتری‌ها، ویرایش و بایگانی سوابق، اصلاح مانده حساب و جست‌وجو
- کالاها، SKU، دسته‌بندی، واحدهای عدد/کیلوگرم/گرم و مقدارهای کسری، هشدار کمبود و گردش موجودی
- فاکتور چندقلمی، تخفیف، سررسید، دریافت جزئی/کامل، لغو فاکتور و برگشت کالا
- بازپرداخت جزئی/کامل وجه با کلید idempotency، کنترل سقف بازپرداخت و حفظ سابقه رسید
- دفتر خرید تأمین‌کنندگان، ورود موجودی، پرداخت جزئی و مانده پرداختنی
- دفتر مالی عمومی، گزارش فروش فاکتوری، دریافتی، اعتبار مرجوعی، بازپرداخت، مانده مشتریان و بدهی تأمین‌کنندگان
- خروجی PDF و XLSX
- Room با Migrationهای ثبت‌شده تا نسخه ۱۳ و آزمون مسیرهای مهاجرت
- SQLCipher، کلید دیتابیس محافظت‌شده با Android Keystore، PIN مبتنی بر PBKDF2، قفل مجدد در پس‌زمینه و biometric در دستگاه پشتیبانی‌شده
- پشتیبان‌گیری/بازیابی رمزنگاری‌شده برای همان نصب
- نمودارها و تحلیل آفلاین؛ پیش‌بینی فعلی میانگین متحرک است، نه ML آموزش‌دیده

## معماری واقعی

کد در ماژول فعلی `app` و پکیج‌های مجزا قرار دارد:
- `data/local`: Room، Entityها، DAOها و Migrationها
- `data`: Repository و جریان داده
- `domain`: قوانین حسابداری و محاسبات مستقل
- `security`: کلید دیتابیس، PIN و قفل برنامه
- `report`: خروجی PDF و XLSX
- `ui`: صفحه‌ها و اجزای Compose

پروژه هنوز چندماژولی نشده است؛ جداسازی لایه‌ها درون ماژول app انجام شده تا بازنویسی غیرضروری ایجاد نشود. هیچ وابستگی به سرویس ابری یا اینترنت برای عملیات حسابداری وجود ندارد.

## داده‌های اولیه

واردکننده Excel در نسخه فعلی فعال نیست. ثبت، اصلاح، بایگانی و مدیریت مانده مشتری‌ها و کالاها از داخل اپ انجام می‌شود. این انتخاب با تصمیم کاربر برای مدیریت دستی داده‌ها سازگار است. داده ساختگی به‌عنوان داده واقعی وارد نشده است.

## محدودیت‌های باقی‌مانده

- انتشار APK امضاشده Release با کلید جدید و پایدار
- آزمایش نصب، به‌روزرسانی، قفل و عملکرد روی گوشی فیزیکی Xiaomi Redmi Note 13
- پشتیبان فعلی به کلید Android Keystore همان نصب وابسته است؛ انتقال به گوشی دیگر یا بازیابی پس از حذف برنامه پشتیبانی نمی‌شود.
- اعلان محلی بدهی‌های بیش از ۳۰ روز هنوز اضافه نشده است.
- واردکننده Excel عمداً در محدوده فعلی نیست؛ داده‌ها دستی وارد می‌شوند.

## وضعیت امنیت امضا

- کلید/اعتبارنامه امضای قدیمی در تاریخچه مخزن عمومی افشا شده‌اند؛ استفاده مجدد از آن ممنوع است.
- حذف فایل کلید از شاخه جاری، تاریخچه عمومی Git را پاک نمی‌کند.
- انتشار Release فقط با کلید جدید و GitHub Actions Secrets انجام می‌شود.
- Secrets لازم:
  - `RELEASE_KEYSTORE_BASE64`
  - `RELEASE_STORE_PASSWORD`
  - `RELEASE_KEY_ALIAS`
  - `RELEASE_KEY_PASSWORD`
- این چهار Secret در آخرین اجرای CI تنظیم نبودند؛ به همین دلیل ساخت و انتشار Release امضاشده اجرا نشد.
- کلید جدید ممکن است با نصب‌های امضاشده با کلید قبلی سازگار با به‌روزرسانی نباشد. پیش از حذف هر نسخه نصب‌شده، از داده‌ها پشتیبان بگیرید.

## جمع‌بندی وضعیت

کد شاخه فعلی، Lint، ساخت APK Debug و ۳۸ آزمون instrumentation روی شبیه‌ساز را با موفقیت گذرانده است. این به معنی تأیید روی گوشی فیزیکی یا آماده‌بودن Release امضاشده نیست؛ دو مورد آخر به‌ترتیب به آزمایش دستگاه واقعی و چرخش امن کلید امضا نیاز دارند.
