# پادناکِشت — حسابداری بومی و آفلاین اندروید

اپلیکیشن حسابداری داخلی پادناکِشت؛ ساخته‌شده با Kotlin، Jetpack Compose، Material 3 و Room. رابط کاملاً فارسی و راست‌به‌چپ است و تاریخ شمسی و مبلغ تومان را به‌کار می‌برد.

## امکانات فعلی

- مدیریت مشتری‌ها و مانده حساب؛ ثبت اصلاحات مثبت و منفی حساب با شرح
- مدیریت کالا، دسته‌بندی، SKU، واحد فروش و موجودی
- پشتیبانی از مقدارهای کسری برای کیلوگرم، گرم، لیتر و واحدهای مقیاس‌دار
- صدور فاکتور چندقلمی، تخفیف، ثبت دریافت کامل یا جزئی و لغو کنترل‌شدهٔ فاکتور
- ثبت برگشت کالا و بازپرداخت کامل یا جزئی وجه؛ حفظ رسید اصلی، جلوگیری از بازپرداخت تکراری و کنترل سقف مبلغ
- ثبت خرید از تأمین‌کننده، افزایش موجودی، پرداخت جزئی و محاسبهٔ بدهی تأمین‌کننده
- دفتر مالی عمومی، گزارش فروش فاکتوری، جریان نقدی، بازپرداخت‌ها و بدهی‌ها
- خروجی PDF و XLSX
- پشتیبان‌گیری و بازیابی رمزنگاری‌شده از دیتابیس
- PIN محلی، تأخیر افزایشی پس از تلاش ناموفق و ورود زیستی در دستگاه‌های پشتیبانی‌شده
- یادآوری روزانه و اختیاری بدهی فاکتورهای بیش از ۳۰ روز با WorkManager؛ کاملاً آفلاین، پیش‌فرض خاموش و بدون نمایش نام مشتری
- یادآوری محلی و زمان‌بندی‌شدهٔ بدهی‌های سررسیدگذشته، با تنظیم روشن/خاموش و بدون ارسال داده به سرور
- نمودارها و تحلیل‌های محلی؛ پیش‌بینی فعلی میانگین متحرک ساده است و مدل یادگیری ماشین آموزش‌دیده نیست
- تم روشن/تیره و رابط RTL

## معماری و حریم خصوصی

- Kotlin + Jetpack Compose + Material 3
- لایه‌های دامنه، Repository، DAO و Room در ساختار فعلی ماژول `app`
- دیتابیس محلی با SQLCipher؛ کلید دیتابیس با AES-GCM و Android Keystore محافظت می‌شود
- عملیات اصلی بدون اینترنت طراحی شده‌اند و مجوز دسترسی اینترنت در Manifest وجود ندارد
- همگام‌سازی ابری، Firebase، Firestore و چنددستگاهی در این نسخه وجود ندارد

**محدودیت پشتیبان‌گیری:** فایل پشتیبان با کلید وابسته به Android Keystore همین نصب رمزنگاری می‌شود؛ بازیابی پس از حذف برنامه یا نصب مجدد، یا روی گوشی دیگر، در نسخهٔ فعلی تضمین نمی‌شود. فایل پشتیبان را جایگزین نسخهٔ نگهداری‌شده در خود گوشی ندانید.

## راه‌اندازی و آزمون

گردش‌کار GitHub Actions در `.github/workflows/android-ci.yml` این مراحل را اجرا می‌کند:

1. آزمون‌های واحد
2. ساخت APK آزمایشی Debug و محاسبهٔ SHA-256
3. آزمون‌های instrumentation و UI روی شبیه‌ساز Android API 35
4. ذخیرهٔ APK و تصاویر/گزارش‌های آزمون به‌عنوان Artifact

برای ساخت محلی، با Android SDK و Gradle سازگار:

```bash
gradle testDebugUnitTest
gradle assembleDebug
gradle connectedDebugAndroidTest
```

برای `connectedDebugAndroidTest` باید شبیه‌ساز یا دستگاه متصل باشد.

## ورود اطلاعات

واردکنندهٔ Excel در این نسخه فعال نیست. مشتری‌ها، کالاها، مانده‌های اولیه و اصلاحات حساب از داخل برنامه قابل ثبت و ویرایش دستی هستند. هیچ دادهٔ نمونه‌ای به‌عنوان دادهٔ واقعی کسب‌وکار درج نمی‌شود.

## امضای انتشار

کلید و اعتبارنامهٔ امضای قبلی در تاریخچهٔ مخزن عمومی افشا شده‌اند و نباید دوباره استفاده شوند. فایل‌های کلید از شاخهٔ جاری حذف شده‌اند، اما حذف فایل از شاخه به معنی پاک‌شدن تاریخچهٔ عمومی نیست.

انتشار نسخهٔ Release فقط پس از تولید کلید جدید و ثبت این چهار GitHub Actions Secret انجام می‌شود:

- `RELEASE_KEYSTORE_BASE64`
- `RELEASE_STORE_PASSWORD`
- `RELEASE_KEY_ALIAS`
- `RELEASE_KEY_PASSWORD`

تا پیش از آن، CI فقط APK آزمایشی Debug می‌سازد و انتشار امضاشده را عمداً رد می‌کند.
